## Reporting a Vulnerability

Security and student anonymity are paramount to the MIT Mysore Feedback System.

If you believe you have discovered a security vulnerability regarding authentication, session leakage, data privacy, or student identity de-anonymization:

1. **Do not publicly disclose the issue** on GitHub Issues or social channels.
2. Email the maintainer directly at: **feedback.mitmysore@gmail.com** with:
   - Detailed description of the vulnerability.
   - Steps to reproduce or a proof of concept.
   - Potential impact of the issue.
3. You will receive an acknowledgement within **48 hours**, followed by status updates and remediation steps.
